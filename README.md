# sk-226.github.io

Personal site built with [Quartz 4](https://quartz.jzhao.xyz/).

## Development

```bash
npm install
npx quartz build --serve
```

Open http://localhost:8080

## Content

Edit Markdown files in `content/` to update pages. The dev server watches for changes automatically.

## Deploy

Push to GitHub and configure GitHub Pages to deploy from the `gh-pages` branch, or use `npx quartz build` to generate static files in `public/`.
